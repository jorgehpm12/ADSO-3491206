01-emmet

Plugin for faster HTML and CSS coding.

01-Child >
Creates child elements (nesting).

example

ul>li>a ↔️

resultado

<ul> <li><a href=""></a></li> </ul>

02-sibling >
Creates sibling elements.

example

section+header+nav ↔️

result

<ul> <li><a href=""></a></li> </ul>

03-multiplication >
Repeats elements multiple times.

example

ul>li*3 ↔️

result

<ul> <li></li> <li></li> <li></li> </ul>

04-class >
Creates a class attribute.

example

div.contenedor ↔️

.contenedor2 ↔️

result

<div class="contenedor"></div>

05-classes
Creates multiple class attributes.

example

div.clase1.clase2.clasen ↔️

result

<div class="clase1 clase clasen"></div>

06-id
Creates an ID attribute.

example

nav#menu ↔️

result

<nav id="menu"></nav>

07-text
inserts text content.

example

div{Lorem Ipsum Dolor} ↔️

a{Click Aquí}

result

<div>Lorem Ipsum Dolor </div> <a href=“”>Click Aquí</a>

08-custom attribute
Creates custom attributes.

example

a[href=www.google.com] ↔️

result

<a href="www.google.com"></a>

09-Item Numbering
09-Item Numbering

example

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

result

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering
Inverts numbering order.

example

ul>li.num$@-*3 ↔️

result

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Numbering
Defines a base number for sequences.

example

ul>li.num$@3*4 ↔️

result

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Moves up one level.

example

section>article>div^p

result

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping
Groups elements together. Agrupa elementos juntos.

example

(header>nav)(section>article) ↔️

result

(header>nav)(section>article) <header> <nav></nav> </header> <section> <article></article> </section>
